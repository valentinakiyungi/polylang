Ask in any language. Answer from every language.

Polylang is an open-source question-answering service for knowledge bases written in many languages. It finds the right passages wherever they are, answers with citations, and remembers what it has already answered, even when the next person asks in another language.

Built for knowledge that doesn't live in one language

Policies in English, field reports in Kiswahili, partner documents in French. Polylang treats them as one knowledge base.

Search across languages

A multilingual embedding model places questions and documents from more than 50 languages in one shared space, so a Russian question finds an English answer. Keyword search runs alongside it to catch exact names, codes and rare terms.

  • Meaning + keyword search
  • Rank fusion
  • Collections

Answer once, reuse everywhere

Every answer is saved with the meaning of its question. A later question that means the same thing, however it is worded and whatever language it is in, gets the saved answer instantly. No search, no LLM call.

  • Adjustable match strictness
  • Expiry and size limits
  • Cleared when documents change

Answers you can check

Each answer is written in the asker's language and cites the numbered passages it used. Click a citation to see the original text. When nothing relevant is found, Polylang says so instead of guessing.

  • Numbered citations
  • Answers in the asker's language

Your server, your choice of model

Run it with no LLM at all, where it quotes the most relevant sentences, or connect OpenAI, Anthropic Claude, any OpenAI-compatible server, or a local Ollama model. If the model fails, it falls back to quoting.

What happens when you ask

Five steps, most of which are skipped when the question has effectively been asked before.

  1. Understand the question

    The question is turned into a vector with paraphrase-multilingual-MiniLM-L12-v2, a model that gives the same meaning a similar vector in any of its 50+ languages.

  2. Check the saved answers

    The vector is compared with every previously answered question in one step. If one is close enough, its answer is returned straight away.

    Close match found: answered in about a millisecond

  3. Search the documents

    Meaning-based search finds passages that say the same thing in any language. Keyword search finds exact terms. The two rankings are fused, rewarding passages that rank well in either.

  4. Write the answer

    The best passages are numbered and handed to the answer writer, which replies in the question's language and cites what it used.

  5. Remember it

    The answer, its sources and the question's vector are saved for next time. Adding or removing documents clears saved answers, so they never go stale.

Running in two minutes

Install with pip or Docker, load the bundled multilingual sample, and open the web app at http://127.0.0.1:8001.

With pip
# Python 3.10 or newer
git clone https://github.com/valentinakiyungi/polylang.git
cd polylang
python3 -m venv venv && source venv/bin/activate
pip install -e ".[files]"

polylang ingest data/samples/knowledge_base.jsonl
polylang serve
With Docker
git clone https://github.com/valentinakiyungi/polylang.git
cd polylang
docker compose up --build

# Optional: answer with a local model
docker compose --profile ollama up -d
docker compose exec ollama ollama pull llama3.1
On a slow connection? The full install downloads PyTorch and a 470 MB language model. Add --offline to any command to try Polylang without them. Search then matches by spelling rather than meaning, so it isn't cross-lingual, but everything else works.
